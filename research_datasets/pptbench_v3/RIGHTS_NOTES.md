# PPTBench-V3 inventory and rights notes

Dataset: https://huggingface.co/datasets/Wenkaiwang/PPTBench-V3

The README describes a PowerPoint layout-repair evaluation set with 134 decks and 1,608 tasks across three difficulty tiers and four information-density levels. It describes `dataset_final/` as about 7.2 GB and a separate LibreOffice rendering environment as about 0.50 GB. The Hub API reported 5,820,620,613 storage bytes at revision `608f01bf879d6870475f37b370c685a0b8938987`; the README itself points to revision `d44f4be4e4db8c66a626a1bcf74de0f2ffdd3566`, so these are recorded as different versions rather than reconciled.

The Hub card uses `license: other` and directs readers to its provenance section. That section says source decks came from third-party template sites and copyright remains with original creators. The local inventory therefore does not treat the derived task materials as a blanket licence for the underlying slides. Only the README/card was downloaded; no task images, PowerPoint files, repair artifacts, or rendering environment were downloaded.
